Welcome to my Github repository where I made all my code available for the public. This code have been accumulated throughout the year for my thesis project called: "Effects of Synaptic Heterogeneity on Dynamics and Learning Performance in Recurrent Neural Networks".

It is divided into 4 categories:

1. Code for activity plots (including eigenvalue spectra, and total weight distributions) which include:
- "Analysis_of_Activity"
- "simulations_Activities"

2. Code for maximal lyapunov exponent calculations which include:
- "module_tanh_LLE"
- "LLEs_Analysis"
- "LLE_PR_activities_module"
- "simulations_LLEs"

3. Code for participation ratio calculations which include:
- "simulations_PRs"
- "LLE_PR_activities_module"
- "PRs_Analysis"

4. Code for RLS-FORCE learning with internal weight (J) updates which include:
- "FORCE_Local_and_Parallel_Data_Analysis"
- "FORCE_module"
- "simulations_FORCE"
- "simulations_FORCE_HSMs_Gains_Seeds"
- "Random_Search_Param_Optimization_for_FORCE"
